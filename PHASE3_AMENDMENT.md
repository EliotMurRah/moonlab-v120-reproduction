Unavoidable shared surfaces, declared: the public ctypes decoder ABI

DEM->edge translation (merge parallel edges p = p1(1-p2)+p2(1-p1); weight ln((1-p)/p);
correlated pair strengths accumulated identically) — these are interface and mathematics,
not authorship. All statistics, gating, and orchestration are written fresh.

uniform circuit-level depolarization p on after-Clifford / after-reset / before-measure /

MoonLab decodes the SAME shots in plain and correlated modes via the public ABI.
